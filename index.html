    Du téléphone à l'ordinateur, ou l'inverse, sans compte : un lien qui contient vos données chiffrées, et un code affiché seulement sur cet appareil. Ouvrez le lien sur l'autre appareil, entrez le code, puis confirmez.

    Installer l'application

    Sur l'écran d'accueil, sans magasin d'applications

    WealthMorand s'installe sur l'écran d'accueil comme une application : icône, plein écran, et fonctionne sans connexion. Rien à télécharger d'un magasin d'applications.

    Elle est déjà installée sur cet appareil : ouvrez-la depuis l'écran d'accueil. Le bouton ci-dessous sert à la réinstaller au besoin.

    Sur iPhone, l'application installée garde ses propres données, séparées de Safari : restaurez votre sauvegarde une fois dans l'application (page Données).

    Valeurs confirmées

    Touchez ✓ à côté d'une valeur, dans les panneaux « Modifier », quand elle vient d'un document fiable : état de compte RAMQ, relevé de prêt, avis de cotisation.

      Apparence et rapport

      Thème, outils avancés, rapport PDF

      Probabilité de réussite, répartition des placements, trésorerie, comparer deux plans, détail pour le comptable… Cachés par défaut pour garder les pages épurées ; rien n'est retiré.

      Le rapport complet, mis en page avec graphiques en couleurs : couverture et chiffres clés, revenu, impôt, budget, dettes, patrimoine, dossier pour vos proches s'il est rempli, hypothèses et sources. La fiche d'une page résume l'essentiel pour votre partenaire ou votre conseiller ; le sommaire pour le comptable rassemble, sur une page, les revenus, les déductions, l'impôt estimé, les échéances et les documents à fournir. Dans la fenêtre qui s'ouvre, choisissez « Enregistrer en PDF » (sur iPhone : Partager, puis Enregistrer dans Fichiers).
